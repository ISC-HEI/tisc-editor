# Comments

Comments let you review a document with other people, directly on the preview.

## Who can comment

| Role | Read comments | Add and reply | Resolve and delete |
| --- | :---: | :---: | :---: |
| Owner | ✅ | ✅ | ✅ all comments |
| Editor | ✅ | ✅ | Own comments |
| Commenter | ✅ | ✅ | Own comments |
| Viewer | ✅ | ❌ | ❌ |

A **commenter** can read the project and comment, but cannot edit it. The owner can choose this role when [sharing the project](../projects/sharing) or when accepting an access request.

## Add a comment

1. Right-click where you want to comment on the preview.
2. Choose **Add comment**.
3. Type your comment in the side panel and press **Enter** (**Shift + Enter** adds a new line).

A pin appears on the page. It stays attached to the paragraph, even when text is added or removed above it.

## Read and reply

Click the **comments** button in the preview toolbar to open the panel, or click a pin on the page. Click a comment in the panel to scroll to it and reply.

When someone replies to your comment, you receive an email.

## Resolve or delete

- **Resolve** hides the pin and moves the thread to the **Resolved** tab. It can be reopened at any time.
- **Delete** removes the comment for good (deleting the first comment removes the whole thread).

The project owner and the author of the comment can resolve and delete it.
