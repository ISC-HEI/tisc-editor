# File Management

The file explorer is accessible from the menu on the left side of the editor.

## Adding files and folders

You can add a file or a folder using the buttons at the top of the file explorer, or by importing existing media directly.

:::tip[Working inside a folder]

If you click on a folder, it becomes the active target: the next action you take (adding a file, adding a folder, or importing media) will happen inside that folder.

:::

## Previewing images

Hovering over an image file in the explorer shows a preview of it, without needing to open it.

## Deleting and renaming

Files and folders can be deleted or renamed directly from the file explorer.

## Setting the main file

For `.typ` files, you can use **Set as main file** to define which file is compiled as the entry point of the project.

## Opening files

Some files cannot be opened directly in the editor — this is the case for binary files such as images. When you try to open a file of an unrecognized type, the editor will ask you how you want to proceed.

:::warning[Opening binary files]

Opening a binary file may corrupt your project. Only proceed if you know what you are doing.

:::
