# Storage

Each user has **10 MB** of storage available on the TISC Editor.

## How storage is counted

Your storage usage is calculated based on the files saved across your projects. This includes all files stored in projects you own.

:::info[Storage count]

If a project is shared with you, it does not count towards your quota.

:::

## Requesting more storage

If you need more space, you can request an increase from the person who maintains the platform.
