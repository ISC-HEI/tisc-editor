# Downloading a project

You can download a whole project as a **ZIP** archive directly from the dashboard, without opening it in the editor. It is useful to keep a local backup, to work on the files with other tools, or to send the sources to someone who is not a member.

1. Click on the **...** menu of the project.
2. Click on **Download**.

A file named after the project (for example `My report.zip`) is downloaded by your browser.

:::tip[Available for everyone]

You can download any project you have access to, whatever your role: owner, editor, commenter or viewer.

:::

## What is in the archive

- All the files of the project (source files, images, fonts, etc.).
- The folder structure, exactly as it appears in the file explorer of the editor.

The archive contains the **sources** only, not the compiled document. To get the rendered result, use the [PDF or SVG export](../editor/export) from the editor.

:::note[Same as the editor export]

The archive is the same as the one produced by the ZIP export of the editor. You can import it back later into a project through the [file management](../editor/files) features.

:::
