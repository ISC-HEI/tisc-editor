# Duplicating a project

Duplicating a project creates an independent copy of it. It is useful to start from a project you already wrote, to try something without touching the original, or to get your own version of a project shared with you.

1. Click on the **...** menu of the project.
2. Click on **Duplicate**.

The copy appears in your projects, with the same name followed by **(copy)**.

:::tip[Available for everyone]

You can duplicate any project you have access to, whatever your role: owner, editor or viewer.

:::

## What is copied

- The content of the project (all its files).
- Its tags.

## What is not copied

- **The members.** The copy is private: you are its only member, and you are its owner, even if you were only an editor or a viewer on the original. If you want to work with others on the copy, you have to [share it](./sharing) again.
- **The thumbnail.** It is generated again the next time you open and save the copy.

:::note[Archived projects]

If you duplicate an archived project, the copy is **active**. You will find it in your normal project list, not in **Inactive projects**.

:::

:::warning[Storage]

The copy belongs to you, so it counts toward **your** storage quota, even if the original belongs to someone else. If you don't have enough space left, the duplication is refused.

:::

## Changes are independent

Once duplicated, the original and the copy are completely separate. Modifying one has no effect on the other.
