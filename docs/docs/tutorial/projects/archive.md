# Archiving a project

Archiving a project gives you more space and a cleaner workspace. When you are no longer using a project, or when it has ended, you can archive it.

1. Click on the **...** menu.
2. Click on **Archive**.

The project is now accessible by clicking on **Inactive projects**.

:::note[Filtering]

When you filter projects by tags or by name, inactive projects are also filtered.

:::
