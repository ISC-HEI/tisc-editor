# Create a project

:::tip[Good to see you here]

If you can see this page, it means you have access to the editor.

:::

Now that you want to create a project, you just have to click on the **New project** button at the top of the dashboard.

## Templates

When creating a project, you can start with a blank project or choose one of the official ISC templates.

| Name | Utility |
| --- | --- |
| ISC-HEI Exec Summary | Template for writing an executive summary |
| ISC-HEI BThesis | Template for writing a bachelor’s thesis |
| ISC-HEI Report | Template for writing a report |
| ISC-HEI Document | Template for writing a small document |
| ISC-HEI TB Assignment | Template for writing a TB assignment |
| ISC-HEI Poster | Template for making posters |

You just have to select the template you want and add a name.

## Tags

When creating a project, you have the option to add tags to it. Tags are useful to categorize your projects and to filter them.

:::warning[Maximum tags]

A maximum of 10 tags is authorized per project.

:::

## Last step

Just click on **Confirm and Create** and your project will be created.

This step can take up to 20 to 30 seconds if you use a template, because it needs to download it from GitHub.
